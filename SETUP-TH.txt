คู่มือติดตั้งระบบซิงก์ (อ่านก่อนเริ่ม)
1) สำรองข้อมูลงานเดิมจากเว็บเดิมก่อน โดยไปที่ ตั้งค่า > สำรองข้อมูล แล้วเก็บไฟล์ JSON ไว้
2) ใน Supabase เปิด SQL Editor แล้วรันเนื้อหาในไฟล์ SUPABASE-MIGRATION.sql เพียงครั้งเดียว
3) เปิดไฟล์ config.js แล้วใส่ Project URL และ Publishable key (หรือ anon/public key รุ่นเก่า) จาก Supabase Project Settings > API Keys
   - ห้ามใช้ service_role หรือ secret key
4) อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ไปยัง GitHub repository โดยแทนที่ไฟล์เดิม รวม config.js และ SUPABASE-MIGRATION.sql ไม่จำเป็นต้องอัปโหลดไฟล์ SQL ก็ได้
5) รอ GitHub Pages อัปเดต จากนั้นเปิดเว็บใหม่ รีเฟรชแบบ hard refresh (Ctrl+F5) แล้วเข้าสู่ระบบ
6) ถ้าบัญชีนี้ยังไม่มีงานในฐานข้อมูล และเครื่องนี้มีงานเดิมใน localStorage ระบบจะนำงานจากเครื่องนี้ขึ้น Supabase ให้อัตโนมัติ
7) ถ้าฐานข้อมูลมีงานอยู่แล้ว ระบบจะโหลดงานจาก Supabase มาแสดงแทนงานในเครื่องนี้
ข้อควรระวัง:
- ก่อนติดตั้งให้สำรองข้อมูลเดิมทุกเครื่อง
- อย่าล้างข้อมูลเบราว์เซอร์จนกว่าจะตรวจว่าข้อมูลขึ้นบน Supabase แล้ว
- ไฟล์แนบยังเก็บเป็นข้อมูลในฐานข้อมูล อาจใช้พื้นที่มาก; จำกัดไฟล์เดิม 2 MB ต่อไฟล์
- เวอร์ชันนี้ซิงก์งานระหว่างอุปกรณ์หลังเข้าสู่ระบบ แต่การตั้งค่าธีม/ภาษา/เตือนยังเก็บแยกตามอุปกรณ์
- ต้องมีคอลัมน์ task_data ก่อนใช้งาน มิฉะนั้นการซิงก์จะล้มเหลว
